Pit Stop: privacy and data use

Updated 16 October 2026. Pit Stop is Richard Burton’s personal macOS application for his own Tesla account, not a public multi-user service.

What the app uses

After authorization, the app retrieves the vehicle name and identifier, connectivity status, battery level, charging state and estimated range. These support the dashboard and an optional low-battery reminder. It does not request location, camera recordings, account profile information or energy-product data.

Optional control permissions allow the owner to initiate charging, climate and lock commands. Controls require an explicit action and confirmation. The demo uses simulated data and never sends vehicle commands.

Local storage

The latest vehicle reading, selected vehicle, preferences and a local API-use estimate are stored in the Mac’s application-support folder. Client secrets, OAuth tokens and the command-signing private key are stored in the login Keychain. The app does not retain the Tesla account password. A refresh token supports access until it expires or access is revoked.

Services and disclosure

The app communicates with Tesla’s Fleet API and authorization services. Tesla processes requests according to its own privacy notice. This website is hosted on GitHub Pages, which handles ordinary website requests under GitHub’s privacy statement. The OAuth callback URL briefly contains an authorization code and state value. It loads no third-party scripts, analytics or images and provides a link back to the local Mac app.

The app operator does not send vehicle data to an analytics service, sell it, or run a hosted vehicle-data backend. The public key published on this domain is not a credential that can authorize commands by itself.

Control and deletion

The owner can disconnect the app through the Tesla account’s third-party access settings and remove its virtual key using the Tesla app. Revocation prevents future authorized access but does not erase files already on the Mac. Delete Pit Stop’s local application-support data and its credentials from macOS Keychain to remove local copies. Turn off the optional bedtime rule to stop scheduled checks.
